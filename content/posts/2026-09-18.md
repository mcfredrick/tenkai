## Research Worth Reading

**[Position: It is Time to Virtualize Foundation Models with a Self-evolving Operating System Layer](https://arxiv.org/abs/2609.19203)** — Argues today's agentic stacks are a mess of implicit runtimes for state, memory, budgets, and guardrails baked into every framework. Proposes virtualizing foundation models behind a self-evolving OS layer so agent behavior becomes portable and governable instead of framework-locked.

**[MAGS: Multi-agent Auto-formalization Guarantees Safety for Agentic Outputs](https://arxiv.org/abs/2609.19391)** — Uses multi-agent auto-formalization to apply formal verification to LLM-generated code, catching the safety and security failures fuzzing and static analysis miss. If you're going to let agents write code, this is the kind of safety net you want.

**[Closed-World Resolution Against Tool Hallucination in LLM Agents](https://arxiv.org/abs/2609.19425)** — Identifies a fun failure mode where agents call tools that don't exist and pass arguments nobody declared — tool selection and gating don't catch it. The closed-world resolution approach constrains calls to declared schemas, which sounds obvious until you see how often it's missing.

**[QVAC Genesis III: A Large-Scale, High-Quality Open Synthetic STEM Corpus for Efficient Language Model Pre-Training](https://arxiv.org/abs/2609.19513)** — Large-scale synthetic STEM corpus aimed at efficient pre-training for educational models, especially on edge devices with tight token budgets. Addresses the shortage of open, high-per-token-value STEM datasets — useful if you're training small models on a budget. 📄

**[Layer-wise Curriculum Learning for Efficient LLM Compression](https://arxiv.org/abs/2609.19213)** — Transfers knowledge from teacher to student using progressively harder optimization tasks per layer. A solid efficiency play for compressing LLMs without the usual one-shot distillation roulette.

**[Block Parallelism For Efficient Distributed Long-Context Diffusion Language Model Training](https://arxiv.org/abs/2609.19242)** — Shards sequences differently than conventional context parallelism to cut distributed attention communication and activation memory overhead. Worth a read if long-context diffusion training is your particular flavor of suffering.

## Today's Synthesis

Two things that should never be combined: LLM agents and undeclared tool calls. The [closed-world resolution paper](https://arxiv.org/abs/2609.19425) identifies a failure mode where agents call tools that don't exist and pass arguments nobody declared — and tool selection and gating miss it entirely. The fix is mechanical: enforce declared schemas at the boundary. If you're building with [Mcp-Agent](https://github.com/lastmile-ai/mcp-agent), that means a validation middleware that checks every tool call against its declared schema before dispatch — not a prompt instruction, an actual hard check. This matters double when the tool is something like [pg-mcp](https://github.com/stuzero/pg-mcp), where a hallucinated argument isn't a fun bug, it's a malformed query against your production database. The paper's point is that this class of error survives selection and gating, so the schema contract has to be enforced in the harness, not the model. Treat MCP's declared schemas as an API contract, validate every call, and let the agent fail loudly on a 400 instead of silently doing the wrong thing.
