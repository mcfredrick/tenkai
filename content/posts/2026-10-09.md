## Model Releases
- **[GLM5.3-Flash-E224-DGX-Spark](https://huggingface.co/autotrust/GLM5.3-Flash-E224-DGX-Spark)** — Expert-pruned MoE variant of GLM-5.3-Flash, optimized for NVIDIA DGX Spark (GB10) with nvfp4 quantization and modelopt compression, enabling 8-bit image-text-to-text generation for conversational en/zh workloads. 🤖
- **[Whistle](https://huggingface.co/Cactus-Compute/whistle)** — ASR model optimized for on-device edge deployment via WebAssembly and advanced quantization, supporting English and multiple European languages with real-time inference and reduced model size. 🛠️
- **[LiquidAI/d1-3B](https://huggingface.co/LiquidAI/d1-3B)** — Multimodal decision-model based on LFM2.5-VL-3B, featuring system-one reasoning, calibrated probabilities, and edge-optimized inference for multilingual conversational tasks, with custom-code integration for decision-flow automation. 🤖
- **[unsloth/embeddinggemma-2-GGUF](https://huggingface.co/unsloth/embeddinggemma-2-GGUF)** — GGUF-quantized version of Google's embeddingGemma-2, enabling multimodal feature extraction across vision, audio, and video with sentence-similarity search, optimized for edge and conversational retrieval. 📄
- **[humanizer](https://huggingface.co/jialinyyzz/humanizer)** — Gemma-4-based finetuned model for text rewriting, paraphrasing, and style transfer, supporting English and Chinese conversational inputs, compatible with llama.cpp and transformers pipelines via safetensors and gguf. 🛠️
- **[ema-lightning](https://huggingface.co/canberkkkkkk/ema-lightning)** — TTS model using flow-matching for efficient Turkish speech synthesis, released with an arXiv preprint demonstrating training and inference pipelines, targeting low-resource language TTS with high-quality audio and minimal latency. 🤖

## Open Source Releases
- **[exllamav3 1.6.0](https://pypi.org/project/exllamav3/1.6.0/)** — Inference optimization library update enabling efficient local LLM execution on modern consumer GPUs with reduced memory overhead, expanding model compatibility and improving token throughput for real-time deployment. 🛠️
- **[anthropics/claude-code v2.1.295](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)** — Release adds onFailure: "block" hook mode to prevent unintended command execution when hooks fail, plus OSC 7501 support for terminals to display Claude Code's working state (waiting, processing, etc.). 🛠️
- **[omnismart-personas 0.1.6](https://pypi.org/project/omnismart-personas/0.1.6/)** — Introduces role-based, data-scoped LLM persona templates integrated with a routing framework for production analytics copilots, addressing scoped access control and persona management in LLM-driven data analysis workflows. 📄
- **[intelai 0.1.8](https://pypi.org/project/intelai/0.1.8/)** — Releases a persona-aware AI analytics and RAG copilot framework featuring multi-domain KPI intelligence and GraphRAG-lite implementation, combining graph-augmented retrieval with ML forecasting for domain-specific KPI insights from LLM outputs. 🛠️
