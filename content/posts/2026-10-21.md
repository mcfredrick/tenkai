## Research Worth Reading

**[Pareto-Optimal RTL Code Generation via Multi-Objective Reinforcement Learning with Large Language Models](https://arxiv.org/abs/2610.26904)** — Proposes multi-objective RLVR for LLM-generated RTL circuits, enabling Pareto-optimal Power-Performance-Area trade-offs without scalarized reward aggregation. Introduces verifiable reward signals directly from circuit synthesis metrics for hardware design automation. 🔧

**[Fix, Not Just Resample: Bounded Compiler-Guided Repair in Lean 4](https://arxiv.org/abs/2610.26942)** — Introduces a bounded online step-level repair module for Lean 4 that exploits precise error messages from proof assistants to repair failed LLM tactics, bridging sampling-based theorem proving and verifiable verification. Enables more efficient integration of LLMs with formal proof systems. 🛠️

**[LEAF: LUT-aware Efficient Attention on FPGAs](https://arxiv.org/abs/2610.27078)** — Presents LEAF, the first nanosecond-scale LUT-aware transformer for FPGAs, resolving the trilemma of model performance, FPGA resource fitting, and sub-microsecond latency for real-time systems such as CERN triggers. Enables transformer deployment on resource-constrained reconfigurable hardware. 🔧

**[High-dimensional layer-state trajectories reveal the internal dynamics of transformer inference](https://arxiv.org/abs/2610.26866)** — Treats ordered layer-state trajectories as empirical processes to test whether layer order defines measurable computation across Qwen, Llama, and Gemma checkpoints, extending beyond parameter-level mechanistic interpretability. Provides insights into how inference unfolds through layer dynamics. 📊

**[Expert-Guided Rubrics as Dense Reward Signals for Reinforcement Learning in Non-Verifiable Domains](https://arxiv.org/abs/2610.26932)** — Proposes expert-derived rubrics as dense reward signals for RL training of LLM agents in domains like financial services where traditional verifiers are absent and action consequences must guide policy. Addresses the credit assignment problem in non-verifiable agent deployment. 💡

**[Beyond Policy Discrepancy: Capability-Aware Multi-Teacher On-Policy Distillation](https://arxiv.org/abs/2610.26950)** — Introduces capability-aware allocation in multi-teacher on-policy distillation, using behavioral mismatch metrics to prevent over-supervision when students match or exceed teacher performance. Strengthens student-teacher alignment with capability-aware supervision strength. 🎯

## Today's Synthesis

Combining **LEAF: LUT-aware Efficient Attention on FPGAs** with **Pareto-Optimal RTL Code Generation via Multi-Objective Reinforcement Learning** creates a powerful pipeline for deploying formally-verified, hardware-optimized AI accelerators at the edge. LEAF achieves sub-microsecond transformer inference on FPGAs by designing attention mechanisms that respect LUT constraints, targeting real-time workloads such as CERN trigger systems. The Pareto-Optimal RTL framework complements this by navigating the power-performance-area trade-off through multi-objective RL without relying on scalarization, producing RTL that meets strict timing and resource budgets while retaining formal verification guarantees. Engineers can operationalize this by first authoring the core attention kernel in high-level RTL as described in the LEAF paper, then feeding the synthesized netlist into the Pareto optimizer to co-optimize placement, routing, and clocking under target latency and power constraints—ensuring correctness alongside speed. This synergy enables production-grade AI accelerators for time-series analytics or robotics where microsecond response times and deterministic behavior are non-negotiable, turning theoretical efficiency into deployable, reliable silicon.
