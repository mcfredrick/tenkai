## Model Releases
- [Lakonik/pi-H3](https://huggingface.co/Lakonik/pi-H3) — Flow-matching distilled model for text/image-conditioned audio-video generation, with ComfyUI support and an arXiv paper behind it. If you're poking at joint audio-video synthesis or distillation tricks, it's worth a look 🤖
- [n4ze3m/tiny-voca](https://huggingface.co/n4ze3m/tiny-voca) — Small English TTS model shipping in both ONNX and GGUF. Handly for edge inference experiments where you don't want to babysit a 400MB vocoder.

## Open Source Releases
- [agentic-hil 0.28.0](https://pypi.org/project/agentic-hil/0.28.0/) — Hardware-in-the-loop MCP server that lets a coding agent flash, reset, and drive UART/CAN on actual boards behind debug probes. Ships a pytest plugin, so the hardware gate can live in CI instead of someone's bench notes.
- [visualkit 3.0.1](https://pypi.org/project/visualkit/3.0.1/) — Local-first programmable video editing engine with versioned SQLite timelines, exact rational clocks, and FFmpeg rendering. The rational clocks are the detail that tells you the author has actually been burned by floating-point timestamps.
- [membase-ai 0.4.1](https://pypi.org/project/membase-ai/0.4.1/) — Agent memory layer with a Python client, CLI, and MCP server, hosted or self-run. Another entry in the increasingly crowded "persistent agent memory" category.
- [opendockit 0.3.15](https://pypi.org/project/opendockit/0.3.15/) — Converts PDF, Office, HWP/HWPX, OpenDocument, RTF, EPUB, HTML, email, and images into clean LLM-ready Markdown. The HWP support suggests Korean enterprise document ingestion was the actual problem being solved.
- [skywake 0.4.2](https://pypi.org/project/skywake/0.4.2/) — Branching filesystem for agents backed by an S3 bucket, with vector, full-text, and hybrid search. Git semantics for agent storage, which is either clever or a great way to watch agents lose track of which branch they're on.
- [doubled-graph 3.5.0](https://pypi.org/project/doubled-graph/3.5.0/) — MCP facade over CodeGraphContext and GRACE 4 artifacts, exposing impact analysis, context retrieval, drift detection, and migration workflows. Useful if you want an LLM to answer "what breaks if I touch this" without guessing 🛠️

## AI Dev Tools
- [t3code: remote control for coding agents](https://github.com/pingdotgg/t3code) — Control Claude Code, Codex, and friends from desktop or mobile. Basically a steering wheel for long-running agent sessions, which is the part everyone underestimates until an agent spends 40 minutes confidently refactoring the wrong module.

## Today's Synthesis

The most useful agent setup isn't a bigger model; it's a tighter feedback loop. Pair [t3code](https://github.com/pingdotgg/t3code) with [doubled-graph](https://pypi.org/project/doubled-graph/3.5.0/) and [agentic-hil](https://pypi.org/project/agentic-hil/0.28.0/) so a long-running coding agent can be paused, queried, and gated before it does something expensive. Concretely: when t3code shows the agent about to touch a module, hit doubled-graph's impact analysis to get the blast radius, then require agentic-hil's pytest hardware gate to pass on the actual board before the session can continue. That turns "the agent said it works" into a checkable sequence: remote steering, dependency-aware context, and real hardware validation. It also gives you a clean place to fail fast—if the impact set is huge or the board doesn't reset, stop the run instead of letting it refactor for another 40 minutes. Start with one repo and one board; if the gate is flaky, fix that before adding more agents. The pieces are individually useful, but together they make agent workflows less vibes-based and more like CI with a human in the loop.
