## Model Releases

- **[nvidia/Nemotron-3-Diarization](https://huggingface.co/nvidia/Nemotron-3-Diarization)** — NVIDIA's streaming speaker diarization system integrates Nemo, SortFormer, and GGuF quantization across recent arXiv preprints, delivering real-time speaker tagging and audio-frame classification for production audio pipelines. 🤖
- **[Edge0/Audio8-ASR-Infinite](https://huggingface.co/Edge0/Audio8-ASR-Infinite)** — Transformers-based ASR system enabling real-time streaming speech recognition in Chinese and English, with Apache 2.0 licensing and custom code support for multilingual deployment. 📄
- **[Altworld/Hemingway-1](https://huggingface.co/Altworld/Hemingway-1)** — Qwen3.8-27B fine-tuned model for conversational chat and creative writing, released with endpoints compatibility and CC-BY-NC-4.0 license, targeting English-language interactive applications. 🤖
- **[yandex/AliceAI-Foundation-80B-A3B-Base](https://huggingface.co/yandex/AliceAI-Foundation-80B-A3B-Base)** — MoE language model supporting Russian and English text generation with vllm optimization and Apache 2.0 licensing, built for large-scale deployment across Transformers and safetensors. 🛠️

## Open Source Releases

- **[NVIDIA Model-Optimizer: Unified SOTA Model Optimization Library](https://github.com/NVIDIA/Model-Optimizer)** — Unified open-source library implementing state-of-the-art optimization techniques including quantization, distillation, pruning, NAS, and speculative decoding, compressing models for TensorRT-LLM and TensorRT deployment. 🛠️
- **[triepick 0.1.0](https://pypi.org/project/triepick/0.1.0/)** — Implements a trie-planned candidate scoring algorithm for user-managed vLLM deployments, optimizing token selection and batching efficiency in LLM serving systems while reducing computational overhead. 📦
- **[closecode-ai 0.2.0](https://pypi.org/project/closecode-ai/0.2.0/)** — Agentic terminal coding assistant framework built on LangGraph, OpenRouter, and MCP, enabling automated code generation and terminal interactions via LLM agents for programmable coding pipelines. 🛠️
- **[promptdrift-ci 0.3.1](https://pypi.org/project/promptdrift-ci/0.3.1/)** — CI-integrated framework for regression testing LLM prompts, automatically detecting prompt drift and behavioral shifts across model versions, temperature changes, or dataset modifications for stable production workflows. 🔧
- **[Imbad0202/academic-research-skills - Academic research pipeline for Claude Code](https://github.com/Imbad0202/academic-research-skills)** — Provides academic research skills for Claude Code covering the full pipeline from research → write → review → revise → finalize, automating literature reviews, peer review, and final paper generation. 📄
