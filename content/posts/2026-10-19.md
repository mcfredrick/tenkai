## Research Worth Reading
- [Structured Authority Injection: Persistent Human Control for LLM Agents via Typed MCP Overrides](https://arxiv.org/abs/2610.22373) — Protocol-level typed overrides ensure human operators maintain persistent control across LLM agent planning cycles, avoiding ambiguous free-text override interpretation.
- [From Events to Reasoning: Hierarchical Rule Composition over Explicit States](https://arxiv.org/abs/2610.22403) — Event Reasoning System formalizes hierarchical rule composition that requires every reasoning step to be admissible on available facts, preserving dependencies and allowing premise revision.
- [ECHOES: Seeing Beyond the Current Image via Recursive History Compression and Privileged On-Policy Distillation](https://arxiv.org/abs/2610.22408) — Addresses long-horizon GUI agent token costs by compressing visual history recursively while preserving critical state cues through a privileged on-policy distillation objective.
- [PRIME: Towards Verifiable Evidence-Grounded Reasoning in LLM Agents](https://arxiv.org/abs/2610.22426) — Framework rejecting acceptance when required checks fail, demanding explicit evidence grounding for verifiable reasoning in agent tasks like vulnerability report advisory checking.
- [Learnable Splines for Unstructured Neural Operators](https://arxiv.org/abs/2610.22446) — L-SplineFNO extends Fourier neural operators to unstructured meshes using learnable spline bases, avoiding grid interpolation for engineering simulations on non-rectangular domains.
- [Harness-Delta Attribution: Dissecting Gains From Harness Evolution](https://arxiv.org/abs/2610.22466) — Statistical framework decomposing performance gains from harness evolution into model capacity versus search-space overfitting components.

## Today's Synthesis

A practical local document-understanding pipeline drops two items from today's digest together: Indra-OCR parses handwritten PDFs, complex layouts, and multi-language docs into plain text via ONNX, while Qwen3.8-Flash-Next-FP4-Local delivers near-baseline accuracy on image-text-to-text tasks at FP4. Combine them — feed ONNX-parsed documents directly into the quantized checkpoint for lightweight reasoning, keeping everything on consumer hardware with sub-millisecond parsing and no cloud dependency. The result is a self-hosted document triage system that avoids both the cost of cloud OCR APIs and the accuracy hit of naive local LLMs, which matters when you're processing customer-facing intake forms or internal compliance docs where you can't trust a third-party API and can't afford accuracy loss.
