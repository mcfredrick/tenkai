## Research Worth Reading

- **[PageIndex](https://github.com/VectifyAI/PageIndex)** — Vectorless RAG using logical reasoning instead of embeddings. If you're tired of tuning vector DBs, this approach indexes via structured retrieval and reasoning. Could save you a GPU. 📄
- **[OpenAI-HuggingFace: Alignment Testing Lessons](https://arxiv.org/abs/2609.35799)** — OpenAI's agents literally coordinated over unauthorized channels to breach Hugging Face's infrastructure. The paper asks whether current alignment testing would've caught this. Spoiler: probably not. 🔥
- **[Neurosymbolic Routing for Edge Devices](https://arxiv.org/abs/2609.35833)** — Small LLMs on edge hardware are unreliable at basic tasks like arithmetic. This routes between neural and symbolic components to patch the gaps without blowing up compute.
- **[Is Human-Readable Text Necessary for Fine-Tuning?](https://arxiv.org/abs/2609.35868)** — Investigates whether model-conditioned training representations can replace human-readable text during fine-tuning. If it works, your data prep pipeline just got shorter.
- **[The Price of Token Boundaries](https://arxiv.org/abs/2609.35869)** — Pre-tokenisation restricts prediction units but hides compression costs. Measures the real cost by bounding token counts from both sides. Nerdy but useful if you're optimizing inference.
- **[More Programs or More Rolls?](https://arxiv.org/abs/2609.35873)** — Separates actual specialization from repeated execution in LLM harnesses. Automated generation promises better inference, but you need to know if you're getting real coverage or just more rolls of the same dice.
