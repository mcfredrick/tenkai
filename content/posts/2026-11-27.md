## Model Releases

- **[Aleph-Alpha/Kolibri-1.1](https://huggingface.co/Aleph-Alpha/Kolibri-1.1)** — Another reasoning MoE, but this one ships with vLLM support and FP8 weights, which is the difference between a model card and something you can actually serve. German/English/Arabic coverage is the more interesting bit — that's a genuinely underserved triangle. Apache-2.0, evals included. 🤖
- **[sand-ai/MAGI-2-preview](https://huggingface.co/sand-ai/MAGI-2-preview)** — MoE for synchronized audio-video generation, doing text/image-to-video plus joint audio-video synthesis in one model. Apache-2.0, and "preview" is doing honest work in that name — treat the weights as a moving target.
- **[kandinskylab/Kandinsky-ImageSR-2.0](https://huggingface.co/kandinskylab/Kandinsky-ImageSR-2.0)** — Super-resolution via Diffusers with its own `KandinskyImageSRPipeline`, MIT-licensed. Upscaling is the least glamorous corner of generative models and the one that quietly ends up in production pipelines.

## Open Source Releases

- **[MCP Servers v2.6.0](https://github.com/modelcontextprotocol/servers/releases/tag/v2.6.0)** — Security drop: eight vulnerabilities fixed across three servers, plus two leftovers from v2.5.0. If you run `mcp-server-git`, `server-memory`, or `mcp-server-fetch` — and `server-filesystem` on Windows — go bump them now rather than after the incident review. 🔥
- **[deimos-stream 0.8.0](https://pypi.org/project/deimos-stream/0.8.0/)** — Streaming inference engine aimed at low-VRAM sparse MoE and LLM serving, with MLX, CUDA, and C++17 backends. The pitch is Merkle-paged streaming to keep memory-constrained serving from falling over. 🛠️
- **[curu-caption 3.14.0](https://pypi.org/project/curu-caption/3.14.0/)** — Local-first pipeline that turns media into AI-Toolkit-ready LoRA datasets. Nothing clever, just the dataset-prep step you always end up hand-rolling at 2am. 🛠️
- **[recallix 0.2.7](https://pypi.org/project/recallix/0.2.7/)** — Python client and MCP server for an agent memory layer that does persistence without calling an LLM to do the remembering. Fewer moving parts, fewer surprise summarization artifacts.

## Research Worth Reading

- **[Partial Routing: Trace-Tuned Delegation for Resource-Efficient Agentic Workflows](https://arxiv.org/abs/2611.33402)** — Splits an agentic task so a frontier lead model keeps the hard parts and farms the easy subtasks to cheap models, with the routing tuned on traces. A real cost lever that doesn't require picking one model for the whole workflow. 📄
- **[MGMem: An Efficient, Deterministic, and Provenance-Preserving Framework for Long-Horizon Agent Memory](https://arxiv.org/abs/2611.33174)** — Argues you don't need generative summarization for long-horizon memory: deterministic, provenance-preserving indexing gets you the right past turn out of thousands without the build cost or the nondeterminism. 📄
- **[Constraint-Aware Test-Time Scoring for LLM and VLM Candidate Selection](https://arxiv.org/abs/2611.33161)** — Scores candidate outputs against explicit task constraints instead of trusting model confidence or a judge model. Targets the failures where a fluent answer quietly violates a security or physical-feasibility requirement. 📄
- **[Confidence scores for gated automation of large language models](https://arxiv.org/abs/2611.33394)** — Surveys how to get confidence estimates you can actually gate on, so high-stakes actions don't fire off overconfident garbage. Directly applicable if you're the one who has to sign off on the automation. 📄
- **[Dynamic Reasoning in Next-Gen Detection and Response: An Empirical Study of LLM Triage, Reinforcement Tuning, and Adversarial Evasion](https://arxiv.org/abs/2611.33470)** — Puts static classifiers, graph-based signal fusion, and LLM triage agents head to head under a fixed analyst attention budget, reporting recall at alerts per day. Includes RL tuning and adversarial evasion, which is the part most triage papers skip. 📄
- **[CA-RAG: Constraint-Aligned Retrieval for Structurally Faithful Long-Form Generation](https://arxiv.org/abs/2611.33497)** — Retrieval that optimizes for structural obligations, not just semantic similarity, so mandatory clauses don't get dropped. Worth a look for compliance-flavored RAG where a missing section is a failed document. 📄

## Today's Synthesis

If your agents keep failing because they forget the wrong thing and then act confidently on it, wire [recallix 0.2.7](https://pypi.org/project/recallix/0.2.7/) into your runtime as a deterministic memory store, then use [Partial Routing: Trace-Tuned Delegation for Resource-Efficient Agentic Workflows](https://arxiv.org/abs/2611.33402) to send retrieval, summarization, and tool-selection subtasks to cheaper models while reserving the frontier model for final synthesis. The key is not just “use memory”; it is to make every retrieved memory item carry provenance and confidence metadata, then gate side-effectful actions using the survey-style confidence gating described in [Confidence scores for gated automation of large language models](https://arxiv.org/abs/2611.33394). Concretely: store turns and tool outputs in recallix, generate a trace-tuned routing policy from past failures, and refuse to execute any automation action unless the selected memory has provenance plus a calibrated confidence score above your threshold. That gives you cheaper agents, fewer hallucinated histories, and an audit trail when the model inevitably gets overconfident. 🔥
