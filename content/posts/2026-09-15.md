## Model Releases
- **[tencent/AuK](https://huggingface.co/tencent/AuK)** — Audio toolkit covering zero-shot TTS, voice cloning, source separation, and enhancement via instruction-guided diffusion. Useful if you need a one-stop speech processing stack without stitching together five separate repos.
- **[TokenRhythm/NeoHorse-1-4B](https://huggingface.co/TokenRhythm/NeoHorse-1-4B)** — 4B parameter model fine-tuned from Qwen3.5, focused on agentic tool-use, coding, and reasoning. Small enough to run locally, capable enough for technical tasks.
- **[ukisai/Swift-Qwen3.8-27b](https://huggingface.co/ukisai/Swift-Qwen3.8-27b)** — Token-efficient reasoning for Qwen3.8-27B with LoRA support. Targets reduced inference cost without tanking conversational quality — relevant if you're burning budget on 27B deployments.
- **[nex-agi/Nex-N2.5-mini](https://huggingface.co/nex-agi/Nex-N2.5-mini)** — MoE multimodal model (image-text-to-text) built on Qwen3.5, Apache 2.0 licensed. Straightforward conversational AI deployment option with endpoints compatibility.

## Open Source Releases
- **[mlipaudit 0.1.7](https://pypi.org/project/mlipaudit/0.1.7/)** — Benchmarks ML Interatomic Potentials with standardized test suites, energy/force metrics, and comparison frameworks. 0.1.7 adds more potential families, GPU acceleration flags, and export functionality.
- **[ellf-recipes-gpu 0.1.156](https://pypi.org/project/ellf-recipes-gpu/0.1.156/)** — GPU-optimized training/inference recipes for spaCy-curated transformer models. Mixed-precision configs and benchmarked pipelines for CUDA hardware.

## Research Worth Reading
- **[ZGCM-1](https://arxiv.org/abs/2609.13356)** — 7B dense model for math and agentic search with internal reasoning + external tool use. Fully open, efficiency-focused alternative to bloated larger models.
- **[Root-Cause Attribution as Search](https://arxiv.org/abs/2609.13463)** — Frames agent failure diagnosis as a continual search over execution logs. Automated RCA techniques that turn outcome signals into actionable fixes for long-horizon tasks.
- **[OrchSLM](https://arxiv.org/abs/2609.13470)** — Empirical study of SLM orchestration dynamics in agentic pipelines. Addresses latency, privacy, and compute trade-offs — useful if you're running multiple small models instead of one big one.
- **[Token Efficient Web Agents](https://arxiv.org/abs/2609.13491)** — Models application UI behavior to cut token consumption during web agent task execution. Significant cost savings without tanking success rates.
- **[Derivative-Fidelity Failure in PINNs](https://arxiv.org/abs/2609.13171)** — Function-value accuracy ≠ derivative accuracy in physics-informed neural networks. Strengthened benchmark evidence and training dynamics analysis for scientific ML reliability concerns.
- **[Do Tabular Foundation Models Still Need Feature Engineering?](https://arxiv.org/abs/2609.13202)** — Empirical evaluation across tabular benchmarks. TFMs reduce engineering overhead but feature construction still matters for peak performance on heterogeneous structured data.

## AI Dev Tools
- **[LibreChat](https://github.com/danny-avila/LibreChat)** — Self-hosted ChatGPT clone supporting OpenAI, Anthropic, Groq, Gemini, MCP, langchain, code interpreter, DALL-E-3. Multi-user auth and model switching. Good drop-in for teams wanting local control over their LLM playground.
- **[pi](https://github.com/earendil-works/pi)** — Lightweight AI agent toolkit with unified LLM API abstraction, structured agent loop, terminal UI, and coding agent CLI. Built for rapid prototyping of agent-driven workflows.
- **[cline SDK shared v0.0.83](https://github.com/cline/cline/releases/tag/sdk%2Fshared%2Fv0.0.83)** — Hub-managed agent plugins discovered from `~/.agents/plugins/*`, validated via `plugin.json`. Skills exposed through the skills tool as `plugin-name:skill-name`, with stdio and Streamable HTTP support.
