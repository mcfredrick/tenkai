## Open Source Releases

- **[macos-computer-use-kit 0.3.1](https://pypi.org/project/macos-computer-use-kit/0.3.1/)** — AX-first macOS automation layer for AI agents. Accessibility trees, background input, on-device OCR, deterministic safety policy. No cursor needed. 🍎
- **[akar 0.2.4](https://pypi.org/project/akar/0.2.4/)** — Pure Rust embedded graph DB with Python bindings, built for AI agent memory. Graph-structured storage optimized for agentic workflows. 🗄️
- **[declaw 1.5.1](https://pypi.org/project/declaw/1.5.1/)** — Secure runtime for AI agents: PII scanning, prompt injection defense, network isolation, egress filtering. Policy-driven safety at the execution layer. 🔒
- **[vectros 0.45.0](https://pypi.org/project/vectros/0.45.0/)** — AI platform SDK with hybrid search (vector+keyword), document ingestion, structured records, inference serving. Modular backend for RAG and agentic apps. 🔍
- **[modelproof 1.0.1](https://pypi.org/project/modelproof/1.0.1/)** — Client-side CLI that catches LLM spoofing, masking, and downgrading attacks by analyzing output distributions and behavioral signatures. No persistent storage needed. 🔎

## Research Worth Reading

- **[Didactic knowledge or Clinical Cases? How Data Types Shape Medical Large Language Models](https://arxiv.org/abs/2609.22161)** — Probes how didactic vs. clinical training data differently shapes medical LLM capabilities. Relevant if you're mixing data sources for domain-specific models. 📚
- **[An Affordable AI-Integrated Smart Cane for Multimodal Mobility Assistance of Visually Impaired Users](https://arxiv.org/abs/2609.22277)** — Low-cost AI cane detecting elevated hazards and semantic context, avoiding expensive hardware or cloud dependency. Good example of edge-first assistive design. 🦯
- **[PAANI: On Device Visual Evidence Fusion and Explainable Guidance for River Robot Simulation](https://arxiv.org/abs/2609.22353)** — On-device visual fusion for resource-constrained river monitoring robots, turning imperfect predictions into inspectable guidance. 🌊
- **[Learning 3D biophysical cell properties from 2D images and cell-population statistics](https://arxiv.org/abs/2609.22410)** — Population-supervised framework inferring 3D cellular properties from 2D microscopy when only aggregate stats are available. Interesting semi-supervised approach. 🔬
