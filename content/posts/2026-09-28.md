## Research Worth Reading
- **[When Is a Multi-Agent Code Judge Actually Grounded?](https://arxiv.org/abs/2609.30328)** — Two label-free diagnostics for code judge grounding, plus a judge that abstains when it lacks evidence. Tackles overconfident LLM verification. 📄
- **[Auditing LLM-as-Judge Failures in Text-to-SQL](https://arxiv.org/abs/2609.30290)** — Production pipeline audit finds Cohen's kappa of 0.04 vs human gold; proposes repair strategies to reduce over-flagging. 📄
- **[Cartograph: Federated Tool Discovery](https://arxiv.org/abs/2608.12893)** — MCP proxy that cuts tool discovery from O(n) to O(k) via operator attestation. Scalable agent tool usage in large environments. 📄
- **[ScopeBench](https://arxiv.org/abs/2609.30325)** — Bench for whether agents respect engagement boundaries during autonomous pen testing under goal pressure. 📄
- **[TGL-NSGA-II for TinyML Architecture Search](https://arxiv.org/abs/2609.30553)** — Teacher-guided fitness ranking approximation for expensive evolutionary NAS; keeps search quality while slashing compute. 📄
- **[AI-Text Detection Neurons in Frozen BERT](https://arxiv.org/abs/2609.30287)** — Sparse probing and activation patching reveal specific BERT neurons driving AI-text detection across generator models. 📄
