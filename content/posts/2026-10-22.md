**[BornSim 0.5.8](https://pypi.org/project/bornsim/0.5.8/)** — Library implementing vector Born-series scattering models for continuous random dielectric media, enabling accurate simulation of wave propagation in heterogeneous media. ## Research Worth Reading

**[To Keep or Not to Keep: Learning KV Cache Retention in Disaggregated LLM Serving Systems](https://arxiv.org/abs/2610.28637)** — Investigates learning-based KV cache retention policies for disaggregated LLM serving systems where prefill and decode are separated across node pools with network fabric. The framework adapts cache admission strategies to minimize cross-node data transfer overhead and breaks classical cache policy approaches.

**[SimHack: Predicting the onset of detectable reward hacking before RL training](https://arxiv.org/abs/2610.28707)** — Introduces SimHack, a pre-training analysis framework that predicts detectable reward hacking behavior in LLM code generation before RL training begins. Enabling proactive objective or environment modifications to mitigate obfuscation and training-time degradation.

**[ReAPO: Retry-Aware Policy Optimization for Efficient Exploration in LLM Reasoning](https://arxiv.org/abs/2610.28770)** — Proposes ReAPO, a retry-aware policy optimization framework that introduces dependence into rollout sampling by incorporating incorrect solutions into subsequent attempt contexts. The method reduces redundant failed strategy exploration and improves reasoning efficiency under RLVR for LLM agents.

**[Teaching AI Agent to Play Poker Strategically Through Preference Optimization](https://arxiv.org/abs/2610.27028)** — Evaluates preference optimization for improving strategic behavior in poker agents under hidden information, demonstrating that PO can surpass static and zero-shot policies in capturing strategic decision-making. The study validates PO as an effective technique for aligning LLM behavior with strategic goals.

**[Scalable Stress-Constrained Topology Optimization: A Super-resolution and Simultaneous Approach Based on Machine Learning](https://arxiv.org/abs/2610.28703)** — Presents SNTO, a machine learning framework jointly representing and optimizing state, adjoint, and design variables via custom neural networks for scalable stress-constrained topology optimization. The super-resolution enabled approach significantly reduces computational cost while maintaining structural integrity.

**[Big Claims, Small Margins: Do Reported GraphLLM Gains Survive Simple Baselines?](https://arxiv.org/abs/2610.28714)** — Critically evaluates reported SOTA gains of graph LLM methods against simple baselines on text-attributed graph node classification splits from recent studies. Findings reveal that many claimed improvements vanish or shrink substantially with proper baseline comparisons, questioning benchmark rigor.

## AI Dev Tools

**[Headroom: Output/Log Compression for LLM Token Optimization](https://github.com/headroomlabs-ai/headroom)** — Compression library and proxy that achieves 20% fewer tokens for coding agents and 60-95% fewer tokens for JSON outputs while maintaining answer accuracy, available as library, proxy, or MCP server integration.

## Today's Synthesis

OmniRoute's [gateway](https://github.com/cheaper-inference/OmniRoute), supporting 1400+ models across 375 providers, already strips 15–95% of tokens via RTK and Caveman compression, while [Headroom's](https://github.com/headroomlabs-ai/headroom) proxy adds another 20% reduction for coding tasks and 60–95% for JSON outputs without sacrificing answer accuracy. Pairing these with [llmswitch-sdk](https://pypi.org/project/llmswitch-sdk/0.1.1/)'s single-client abstraction for OpenAI, Anthropic, Vertex AI, and AI Foundry creates a practical stack: route requests through llmswitch-sdk, auto-fallback to cheaper providers in OmniRoute, then compress every response through Headroom. The result is a token usage drop of over 50% across typical LLM pipelines, directly lowering latency and API costs. Implementation takes under an hour—install the SDK, configure provider priorities, and insert the compression proxy. For teams operating at scale, this concrete pipeline offers immediate cost savings without model changes or code rewrites, making it a realistic upgrade for existing production setups.
