## Model Releases

- **[dealignai/DeepSeek-V4.1-Flash-UNCENSORED-FP8](https://huggingface.co/dealignai/DeepSeek-V4.1-Flash-UNCENSORED-FP8)** — A FP8-quantized, abliterated variant of DeepSeek V4.1-Flash with multimodal MoE support. If you've been hunting for an uncensored, quantized option that doesn't blow up your VRAM, this is worth a look — and a useful signal that FP8 deployment is maturing past the novelty stage.

- **[Agnes-AI/Agnes-3.0-Flash](https://huggingface.co/Agnes-AI/Agnes-3.0-Flash)** — Multimodal model with hybrid-attention long-context reasoning and image-text-to-text capability, trained with custom_code integration. The bilingual English/Chinese focus and extended context handling make it a niche pick for teams working in those languages who need reasoning at scale.

- **[meta-llama/Llama-3.1-8B-Instruct](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct)** — Meta's official open-weight Llama 3.1 8B Instruct, with multilingual support across eight languages and full TGI/SageMaker compatibility. Still a solid baseline if you need a well-supported, no-surprises LLM for production conversational pipelines.

- **[openai-community/gpt2](https://huggingface.co/openai-community/gpt2)** — The classic GPT-2, now spanning transformers, PyTorch, TensorFlow, JAX, TFLite, Rust, and ONNX. It's less about what it can do and more about what it proves: framework interoperability for text-generation is a solved problem, and this model is the reference implementation.

## Open Source Releases

- **[ephemora-cell 1.0.3](https://pypi.org/project/ephemora-cell/1.0.3/)** — An execution layer for untrusted AI-generated code built on capability-based WASM, with enforceable limits on CPU, memory, time, I/O, and filesystem access. If you're running generated code anywhere near production, this kind of sandboxing isn't optional — it's the whole point.

- **[matrx-batch 0.2.92](https://pypi.org/project/matrx-batch/0.2.92/)** — A cost-shield layer for AI workloads that integrates OpenAI and Anthropic Batch APIs with a live/batch urgency router and shared embedding cache. It's the kind of package that quietly saves real money when you're routing thousands of requests and need to decide what actually warrants the fast path.

- **[leai 0.3.5](https://pypi.org/project/leai/0.3.5/)** — Oracle Database reverse engineering and lineage tracing to feed RAG/LLM documentation pipelines. It generates context-aware documentation from existing schemas, which is the unglamorous but essential work of keeping LLM-facing knowledge bases from rotting into hallucination fuel.

## Research Worth Reading

- **[NeMo Data Designer: An Extensible Framework for Multimodal Synthetic Data Generation](https://arxiv.org/abs/2609.17699)** — An open-source framework for generating multimodal synthetic data (text, code, images, embeddings) via declarative column configuration. If you're tired of manually stitching together training datasets across modalities, the declarative approach could save you more hours than it costs to learn.

- **[Beyond Static RAG: An Adaptive, Tri-Metric Routing Framework for Efficient Long-Context Inference on Commodity GPUs](https://arxiv.org/abs/2609.17564)** — Proposes a routing framework that dynamically balances prompt compression, KV cache management, and context length to work around the compression paradox on commodity GPUs like the T4. Practical paper if you're squeezing long-context inference out of hardware that wasn't built for it.

- **[Fathom: Per-Query Read Depth for Sparse Decoding over Offloaded KV Caches](https://arxiv.org/abs/2609.17652)** — Introduces a key scan mechanism where each query reads only a configurable number of bits per key channel, enabling sparse decoding over offloaded KV caches. The traffic bottleneck of ranking all keys during top-k steps gets a real reduction, which matters when your KV cache is living in host memory and every byte counts.

- **[FairCompressAgent: An Agentic Framework for Fairness-Aware Model Compression for FPGA Deployment](https://arxiv.org/abs/2609.17786)** — Integrates fairness-aware pruning and quantization into an agentic framework that balances accuracy, fairness, and cost for FPGA deployment. The dynamic reconfiguration piece is interesting — post-deployment fairness constraint changes without a full retrain is a real pain point.

- **[Making AI-Assisted Claims Independently Challengeable: Publication Authority and a Protocol for Falsifiable Publication Records](https://arxiv.org/abs/2609.17631)** — Formalizes a non-transferable framework for tracking provenance and transitions of AI-assisted claims across evidence, analysis, and correction history. Not a model paper, but a necessary one — if AI-generated claims can't be independently challenged, the whole pipeline loses credibility.

- **[Physics-Constrained Digital Twins for Sensor Integrity in Urban Pedestrian Flow](https://arxiv.org/abs/2609.17635)** — Formalizes stealthy false data injection in city-scale pedestrian sensing and proposes a physics-constrained digital twin with conformal guarantees to detect anomalies. The integration of latent flow modeling with observation physics is a pragmatic approach to a problem that's gotten more real as sensor networks proliferate.

## AI Dev Tools

- **[BrowserSkill for AI Agent Browser Automation](https://github.com/Tencent/BrowserSkill)** — Lets AI agents interact with real, logged-in browsers via CLI and extension without disrupting the user's workflow. Shell-capable automation across any agent is the kind of practical utility that beats the usual "watch a video of a robot clicking buttons" demo.

- **[TencentCloud Octop: Self-Hosted Multi-User Multi-Agent AI Assistant](https://github.com/TencentCloud/Octop)** — A self-hosted platform for multiple users and coordinated multi-agent workflows with private or enterprise deployment in mind. If you need agent orchestration behind your own firewall without sending everything to a cloud provider, this fills a gap that most open-source agent frameworks ignore.
