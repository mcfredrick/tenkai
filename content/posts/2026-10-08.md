## Open Source Releases

- **[JAXtari 0.2.0](https://pypi.org/project/jaxtari/0.2.0/)** — JAXtari 0.2.0 ships GPU-accelerated, object-centric Atari wrappers for JAX-based RL. If you're still training policies on CPU, this is your wake-up call. 🎮
- **[design-graph 2.1.0](https://pypi.org/project/design-graph/2.1.0/)** — design-graph 2.1.0 turns prototype HTML into structured knowledge graphs for LLM agents. Worth a look if you're paying the token tax for agentic web research and want to cut it down. 📄
- **[Anthropic Claude Code v2.1.293](https://github.com/anthropics/claude-code/releases/tag/v2.1.293)** — Claude Code v2.1.293 swaps in Claude Haiku 5.5 as the default with 1M context and new subagent tracking fields. Read the pricing update before your next bill drops. 🤖

- **[kitaru-pydantic-ai 0.3.1](https://pypi.org/project/kitaru-pydantic-ai/0.3.1/)** — kitaru-pydantic-ai 0.3.1 adds recording and replay for PydanticAI workflows. Debugging non-deterministic agent traces just got a lot less painful. 🛠️

## AI Dev Tools

- **[Anthropic Claude Code v2.1.294](https://github.com/anthropics/claude-code/releases/tag/v2.1.294)** — Claude Code v2.1.294 fixes prompt and agent hooks, plus how Stop/SubagentStop hooks are judged. Finally, hooks will actually block what they're supposed to instead of letting the agent bail early. 🛠️
- **[AI SDK cline v0.0.92](https://github.com/cline/cline/releases/tag/sdk%2Fsdk%2Fv0.0.92)** — AI SDK consolidates into a single release line and fixes reasoning suppression for models that choke on `reasoning.effort: "none"`. If your GPT-6 calls were erroring out when you tried to turn off thinking, this is the patch. 🛠️
- **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** — last30days-skill is an agent that scrapes Reddit, X, YouTube, and HN for grounded, recency-aware summaries. Handy for cutting through the noise without manually refreshing feeds for a week. 📰

## Today's Synthesis

Hook fixes in [Claude Code v2.1.294](https://github.com/anthropics/claude-code/releases/tag/v2.1.294) finally make Stop/SubagentStop hooks enforce instead of letting agents bail early, a long-standing frustration when building autonomous pipelines. Pair that with [design-graph 2.1.0](https://pypi.org/project/design-graph/2.1.0/), which converts prototype HTML into searchable knowledge graphs, slashing the token tax LLM agents pay when reasoning over raw web markup. Throw in [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill), which scrapes Reddit, X, and HN for recency-aware summaries, and you can ground your hooked agents in fresh, structured context without reloading a week's worth of feeds. The result is a repeatable workflow: fetch grounded summaries, graph them, feed them to a Claude Code agent with active hooks, and watch it execute instead of hallucinate. You stop worrying about stale RAG, runaway loops, or hooks that pretend to stop but don't, and start shipping deterministic agentic code that actually respects your `reasoning.effort: "none"` settings. For teams tired of watching agents loop endlessly or choke on unstructured text, this three-piece stack offers a concrete upgrade path without switching frameworks or rewriting existing pipelines.
