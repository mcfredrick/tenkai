## Model Releases
- **[MiniCPM5-2B](https://huggingface.co/openbmb/MiniCPM5-2B)** — 2B parameter model focusing on long-context understanding and tool-calling for on-device/edge AI deployment, trained on Math and Code datasets for versatile conversational AI.
- **[Spark-X2.5-4B](https://huggingface.co/XHToken/Spark-X2.5-4B)** — 4B parameter language model based on Spark architecture, compatible with transformers and safetensors frameworks, distributed under Apache 2.0 with US region deployment compatibility for text generation and conversational AI tasks.
- **[K2-Horizon MoVA-36B-A4B](https://huggingface.co/IFM/K2-Horizon-MoVA-36B-A4B)** — 36-billion parameter Mixture-of-Experts model for text generation and conversational AI, featuring open-weights, custom training code support, and multilingual dataset conditioning.

## Open Source Releases
- **[llm-distillery](https://pypi.org/project/llm-distillery/0.1.0/)** — Drop-in proxy for capturing LLM inference traffic, enabling dataset curation and subsequent model distillation to replace large frontier models with smaller, efficient alternatives; addresses the engineering need for reproducible, data-driven model compression.
- **[finefettle](https://pypi.org/project/finefettle/1.13.1/)** — Open-source trust layer designed to improve safety and reliability of AI coding agents through in-session quality monitoring, delegation-safe policies, and evidence-bound verification; directly tackles common failure modes in autonomous code generation.
- **[srforge](https://pypi.org/project/srforge/0.15.4/)** — PyTorch framework for super-resolution research emphasizing simplicity and flexibility via config-file-driven experimentation, providing standardized training loops, benchmark integration, and easy pipeline compatibility for developing and comparing upscaling models.
- **[dbcrust](https://pypi.org/project/dbcrust/0.37.2/)** — Rust-terminal database workbench supporting multiple engines with agent-ready one-shot JSON output, stable exit codes, and read-only guards; includes optional AI integration, SSH/Vault secret management, Python API, and Django ORM analysis, streamlining data pipeline automation.

## AI Dev Tools
- **[context-mode](https://github.com/mksglu/context-mode)** — Optimizes the context window for AI coding agents, achieving 98% reduction in tool output size, persisting session memory, and enforcing routing across 17 platforms via MCP and hooks, significantly improving efficiency and reliability.
- **[camofox-browser](https://github.com/jo-inc/camofox-browser)** — Stealth headless browser designed for AI agents, enabling bypass of Cloudflare, bot detection, and anti-scraping mechanisms; serves as a drop-in replacement for Puppeteer/Playwright to facilitate web interaction.
- **[browser-use](https://github.com/browser-use/browser-use)** — Library designed to make websites accessible for AI agents, facilitating online task automation by addressing the challenge of enabling AI agents to interact with and navigate web content.
