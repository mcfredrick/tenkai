## Model Releases

- **[Aleph-Alpha Kolibri-1 MoE Language Model](https://huggingface.co/Aleph-Alpha/Kolibri-1)** 🤖 A mixture-of-experts model shipping vllm integration and fp8 support out of the box, with reasoning tuned for German and English. Reasonable option if you want MoE efficiency without rewriting your inference stack.
- **[Xing4.0-29B-A4B GGUF Quantized Language Model](https://huggingface.co/Venastine-Research/Xing4.0-29B-A4B-GGUF)** Apache 2.0 GGUF quantization of the 29B-A4B model, ready for endpoints without the licensing headache. Solid pick for local or private cloud serving where you want the weights usable.

## Open Source Releases

- **[ds4: DeepSeek 4 Local Inference Engine for Metal, CUDA, and ROCm](https://github.com/antirez/ds4)** 🛠️ From the Redis guy, a local inference engine for DeepSeek 4 Flash and PRO across Apple, NVIDIA, and AMD backends. Runs locally instead of paying per-token, which is a nice change of pace.
- **[chimeraforge 0.47.0: LLM deployment optimizer with 200k+ GPU measurements](https://pypi.org/project/chimeraforge/0.47.0/)** Backed by ~204k real measurements on consumer GPUs, this gives you cost/perf/safety trade-offs instead of guesses. Useful if you're tired of benchmarking hardware yourself before committing to a serving stack.
- **[turbo-dllm 0.1.6: Distributed training for diffusion language models](https://pypi.org/project/turbo-dllm/0.1.6/)** 🧪 Optimized distributed training for diffusion language models, tackling the usual communication overhead and parallelism headaches. Probably not for the average app dev, but relevant if you're actually training diffusion-based text models.
- **[loci-rag 0.6.3: Local RAG system with MCP server integration](https://pypi.org/project/loci-rag/0.6.3/)** A local "second brain" for RAG over scattered notes, exposing an MCP server for agent integration. Keeps your knowledge base on-prem and offline, which matters more than it used to.
- **[smartmemory-core 1.5.21: Multi-layered AI memory system](https://pypi.org/project/smartmemory-core/1.5.21/)** Combines graph databases, vector stores, and processing pipelines into one memory architecture for long-term context. Handy if your current RAG setup can't keep track of relationships between documents.
- **[claude-code v2.1.289: Deny/ask rule fixes and terminal stability](https://github.com/anthropics/claude-code/releases/tag/v2.1.289)** Fixes deny/ask rules breaking on nested shell commands and stops the terminal from freezing on unclosed `<script>` tags. Essential if you've ever watched the CLI hang mid-session over some malformed code block.

## AI Dev Tools

- **[claude-code v2.1.288: Mod selection API and built-in GitHub CLI](https://github.com/anthropics/claude-code/releases/tag/v2.1.288)** 🛠️ Adds a `$.ui.selection()` API for mods and a built-in `gh` command so you don't need the CLI installed for cloud sessions. Also patches control character leakage from file names, which sounds minor until you've seen the output.
