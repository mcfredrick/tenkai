## Model Releases
- [Unsloth NVFP4-Compressed Qwen3.8-27B](https://huggingface.co/unsloth/Qwen3.8-27B-NVFP4) — NVFP4-compressed Qwen3.8-27B release from Unsloth, optimized for training and inference while maintaining endpoint compatibility. Apache-2.0 licensed, region-US deployed, and built to work with Unsloth's existing transformer optimization toolkit.

## Open Source Releases
- [omlx: LLM Inference Server for Apple Silicon](https://github.com/jundot/omlx) — High-performance inference server for macOS Apple Silicon with continuous batching, SSD-backed caching, and a menu-bar UI for local model management.
- [ragmodel 0.5.0](https://pypi.org/project/ragmodel/0.5.0/) — Modular, provider-independent RAG execution kernel that lets you swap retrievers, embedders, and LLMs without vendor lock-in via a unified pipeline interface.
- [contextlake 7.22.0](https://pypi.org/project/contextlake/7.22.0/) — Local context layer that mirrors repositories, indexes code/docs into a knowledge graph, and serves queries via MCP for source-grounded agent responses.

## Research Worth Reading
- [OGX: An Open-Source, Vendor-Neutral Generative AI Application Server](https://arxiv.org/abs/2608.14580) — Python library and app server implementing OpenAI, Anthropic, and Google APIs with pluggable backends for portable agentic AI pipelines.
- [Forward Pass Domain Adaptation (Without Cross-Layer Backpropagation)](https://arxiv.org/abs/2608.14563) — Proposes forward-pass-only training that ditches backward passes for 2.7–3.2x throughput and ~40% lower peak memory, while keeping off-domain benchmark performance within seed noise.
- [FLOPs vs Real Work: The Importance of Replication in AI Efficiency Assessment](https://arxiv.org/abs/2608.14550) — Shows that reported FLOPs deviate significantly from real execution time/memory due to layer-wise patterns and hardware effects, advocating for replication-based assessment.
- [When to Communicate: Belief Distributions and KL Divergence for Principled Gating in Multi-Agent RL](https://arxiv.org/abs/2608.14559) — Replaces high-variance REINFORCE binary gates with KL-divergence-based communication gating for stable, interpretable multi-agent coordination.
- [Certified Correctness in Neural Constraint Reasoning Requires Symbolic Integration](https://arxiv.org/abs/2608.14569) — Argues neural CSP solvers fail under distribution shift and proposes symbolic integration as necessary for certified correctness.
- [SKILL: Self-correcting Knowledge-guided Iterative LLM Agent for Logic Optimization](https://arxiv.org/abs/2608.14579) — LLM agent framework that iteratively corrects logic optimization errors via knowledge-guided self-correction, tackling sparse rewards and large search spaces.

## AI Dev Tools
- [ai-memory: Long-Term Memory Layer for AI Coding Agents](https://github.com/akitaonrails/ai-memory) — Persistent memory layer for AI coding CLIs, enabling cross-session state retention and vendor-agnostic handoff by serializing task history, decisions, and code artifacts.
- [Anthropic Cybersecurity Skills Taxonomy for AI Agents](https://github.com/mukul975/Anthropic-Cybersecurity-Skills) — Structured dataset of 817 cybersecurity skills mapped to six industry frameworks, providing a standardized vocabulary for evaluating AI agent security capabilities.
- [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — Agent skill that configures coding agents to generate minimal, functional code prioritizing YAGNI, cutting unnecessary output.
