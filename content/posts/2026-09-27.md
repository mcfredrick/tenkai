## Model Releases

- **[StarDoc-AI/TeleOCR](https://huggingface.co/StarDoc-AI/TeleOCR)** — Fine-tunes Qwen2.5-VL for end-to-end document OCR and parsing, with multilingual (zh/en) conversational queries over parsed content. Strong text-generation-inference accuracy across diverse layouts, integrates detection and recognition. 📄
- **[Contrastive-LM/CLM-v0.1-8B](https://huggingface.co/Contrastive-LM/CLM-v0.1-8B)** — Contrastive learning framework on Qwen3-8B that trains a verifier and reranker for text ranking and agent decision-making, aligned with human preferences in retrieval tasks. Practical finetune for ranking/agent pipelines. 📄
- **[Viggle/Qwen-Image-2.1-viggle-turbo](https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo)** — Turbo variant using few-step distillation (DMD) + LoRA for real-time text-to-image and image-editing with minimal quality drop. ComfyUI-optimized, practical for production distilla 🤖

## Open Source Releases

- **[Correctness-validated heterogeneous Laya runtime for Apple Silicon](https://pypi.org/project/laya-apple/1.6.0/)** — Heterogeneous runtime with MLX GPU and Apple Neural Engine support, rigorous validation protocols for reliable AI/ML workloads on Apple Silicon. 🛠️
- **[claude-code v2.1.283](https://github.com/anthropics/claude-code/releases/tag/v2.1.283)** — Gateway hint headers (`x-claude-code-prompt-id`) for LLM gateways to group requests, opt-in via env var. `availableModelsMatch` with exact mode for pinning model versions. 🛠️
- **[claude-code v2.1.281](https://github.com/anthropics/claude-code/releases/tag/v2.1.281)** — Newer Claude Desktop keys support with `blockReadsOutsideWorkingDirectories` and `disableBypassPermissionsMode`. `assume_role` for Bedrock via STS in another account. 🛠️
- **[goose v1.52.0](https://github.com/aaif-goose/goose/releases/tag/v1.52.0)** — Live voice conversations in desktop app, Decisions provider crate (OpenRouter + Jev), Z.AI Coding Plan with streaming tool calls for planning. 🛠️
- **[cline v4.1.21](https://github.com/cline/cline/releases/tag/v4.1.21)** — New ai& provider (OpenAI-compatible, Japan-served open-weight models), refreshed catalog to 6,386 models across 209 providers, default model changes for 19 providers including Claude Opus 5.5. 🛠️
- **[claude-code v2.1.282](https://github.com/anthropics/claude-code/releases/tag/v2.1.282)** — `maxProseWidth` to cap Claude's prose in wide terminals (tables/code blocks unaffected). Startup notice and `/status/claude doctor` for listing ignored/disabled telemetry vars. 🛠️
