## Open Source Releases

- **[DeepGEMM](https://github.com/deepseek-ai/DeepGEMM)** — DeepSeek's new GPU-optimized BLAS library focuses on the matrix mults that dominate training and inference. 🛠️ Drop it in if your current kernels are leaking perf instead of hand-rolling your own.
- **[dspm-memory](https://pypi.org/project/dspm-memory/0.1.9/)** — This package compresses LLM conversation memory without any training, claiming 100% retention of critical constraints. 📄 Worth a look if context window bills are eating your budget, though the retention numbers sound optimistic.
- **[tokenmizer](https://pypi.org/project/tokenmizer/0.6.0/)** — A graph-backed checkpoint and resume tool for LLM sessions, acting as an OpenAI-compatible proxy to keep state alive across context limits. 🤖 Useful for long-running agents, provided you don't mind adding another layer to your stack.
- **[airo-spatial-algebra](https://pypi.org/project/airo-spatial-algebra/2026.10.0/)** — Python utilities for SE(3) pose and transform operations, targeted at robotic manipulation pipelines. 🛠️ Only matters if you're building robots, but it saves you from writing rotation matrices by hand.
- **[quarry-db](https://pypi.org/project/quarry-db/1.5.3/)** — An AI-native database workbench that pairs LLM-generated queries with an enforced constraint kernel. 🛠️ The safety rail is the actual selling point here — keeps agents from dropping your tables by accident.
- **[hugpy-agent](https://pypi.org/project/hugpy-agent/0.1.109/)** — A portable runtime for AI agents built on top of a self-hosted LLM fleet. 🤖 It abstracts fleet management so you get consistent behavior across environments without manual instance juggling.
