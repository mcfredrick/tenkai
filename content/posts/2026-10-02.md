## Model Releases- **[ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-Coder-GGUF](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-Coder-GGUF)** — A highly optimized GGUF model with GSQ quantization, RCO pruning, and MoE adaptations for code and image-text-to-text tasks, built on Qwen3.8-Flash-Next. Technical details include mixed-precision pipelines and structured pruning, with arxiv-validated performance references for engineers who appreciate quantization depth. 🤖
- **[Cloudflare/clef](https://huggingface.co/Cloudflare/clef)** — A post-trained multimodal model converting images to typed output using Qwen3.5/3.8 backbones, featuring structured-output classification and custom-code conversational capabilities. Focus on image-to-typed-output pipelines and Cloudflare deployment compatibility for those needing multimodal-to-text workflows. 📄
- **[Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash)** — A post-trained CLEF variant using Qwen3.5-9B emphasizing image-to-typed-output, multimodal structured-output classification, and custom-code conversational interactions. Technical focus on post-training efficiency, structured-output heads, and Cloudflare systemone deployment compatibility. 🛠️

## Open Source Releases

- **[datris-mcp-server 1.41.0](https://pypi.org/project/datris-mcp-server/1.41.0/)** — MCP server framework for AI-driven data pipeline operations, integrating ETL, AI data quality checks, and vector search across PostgreSQL, MongoDB, Qdrant, and pgvector. Enables localized, AI-augmented data ingestion, transformation, and querying workflows without constant cloud round-trips. 🛠️
- **[haiku.rag 0.92.0](https://pypi.org/project/haiku-rag/0.92.0/)** — Local-first agentic RAG system offering hybrid search, reranking, and multimodal retrieval over personal document collections without requiring a database server. Emphasizes offline operation, citation-aware responses, and minimal infrastructure for privacy-sensitive deployments where data locality matters. 📄
- **[awdk 3.8.43](https://pypi.org/project/awdk/3.8.43/)** — Open-core framework for building AI agents with persistent memory, knowledge graph, code graph, and ReAct reasoning capabilities, available as a local runtime with optional cloud features. Version 3.8.43 adds improvements to agent memory management and backend interoperability for local and fleet deployments. 🤖

## Research Worth Reading

- **[From Proposal to Verified Effect: Praxa, an Evidence-Bound Harness for Governed AI Agent Execution](https://arxiv.org/abs/2610.00015)** — Presents Praxa, a framework explicitly modeling the full agent action lifecycle—proposal, authority, dispatch, verified external effects, and promotion—using deterministic admission, brokered execution, and read-back reconciliation for governed, auditable AI agent deployment. Framework explicitly models the full agent action lifecycle. 📄
- **[Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness?](https://arxiv.org/abs/2610.00025)** — Systematically evaluates whether off-the-shelf small language models can handle common agent harness microtasks (shell approval, memory writes, tool selection, turn ranking), analyzing failure modes and the impact of quantization on eligibility thresholds. Practical evaluation of SLM capabilities for agent harnesses. 🔧
- **[Heavy-Tailed Memory Traces in Long-Horizon Language Agents](https://arxiv.org/abs/2610.00010)** — Explores the shape of memory use in long-horizon language agents under finite context and repeated retrieval, showing memory concentration on a core set while neglecting rare states. Introduces heavy-tailed analysis to characterize memory distribution impacts on agent performance. 🧠
- **[When Do Causal World Models Help Modular LLM Agents](https://arxiv.org/abs/2610.00012)** — Investigates conditions where causal world models add value for modular LLM agents across interdependent services, contrasting observational trace fitting with causal modeling needed for valid intervention-time planning. Analysis of when and why standard world models fail for modular agents. 🤔
- **[Characterizing a Configuration Where Inference-Time PRM-Pruned Fragment Grafting Is Inert](https://arxiv.org/abs/2610.00047)** — Isolates PRM-Pruned Fragment Grafting (PPFG), an inference-time intervention grafting high-PRM prefixes as in-context demonstrations, and characterizes inert conditions across three reasoning models, offering insights into diversity collapse and effective CoT interventions. Characterization of inert conditions and diversity collapse patterns. 📊
- **[Gradient-Aligned Pair Selection for Personalized Preference Optimization](https://arxiv.org/abs/2610.00061)** — Proposes gradient-aligned pair selection for Personalized Preference Optimization, addressing how preference pairs are chosen to align LLM generation with user-specific rather than aggregate preferences, improving personalization stability and fidelity. Approach to user-specific preference alignment over aggregate optimization. 📈
