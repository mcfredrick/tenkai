## 🏴‍☠️ Open Source Booty Releases ⚓

- **[cgh 0.13.0](https://pypi.org/project/cgh/0.13.0/)** — Ahoy, matey! cgh scuttles yer whole repo into an embedded graph database (DuckDB by default, SQLite in standalone) with full-text search, then hands ye 50 MCP tools fer Claude Code, Cursor, Codex, an' Gemini. It'll even federate across sibling repos, so ye can plunder the whole fleet at once. 🦜

- **[docling-project/docling](https://github.com/docling-project/docling)** — A document-provision' library that turns PDFs an' Word files into structured, LLM-ready booty. If ye've ever wrestled a PDF parser, ye know why this be worth a parley. ⚓

- **[MCPShark: Traffic Inspector for Model Context Protocol](https://news.ycombinator.com/item?id=46220577)** — Avast! MCPShark be a Wireshark for MCP traffic, lettin' ye capture, filter, an' dissect every request an' response. When yer agent's messages be vanishin' into the briny deep, this be how ye find the Kraken. 💀

- **[Claude Code v2.1.278: server-side auto mode classifier default](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)** — Auto mode now defaults to the server-side classifier on Claude API, Enterprise, Bedrock, Vertex, Foundry, an' gateways, so ye ain't billed fer classifier overhead. Ye can opt out on Bedrock/Vertex/Foundry/gateways with `CLAUDE_CODE_AUTO_MODE_SERVER=0`, but a warning be shown on billed fallback. ⚓

- **[flowproof 0.23.9](https://pypi.org/project/flowproof/0.23.9/)** — Records a bot doin' a task once, then replays it on every commit with zero LLM calls to verify the scallywag only does the assigned job an' never pulls a mutiny. Built fer agents an' RPA in production across web, desktop, SAP, an' Citrix. 🏴‍☠️

- **[funcyflows 0.2.1](https://pypi.org/project/funcyflows/0.2.1/)** — Implements normalizin' flows an' flow matching on function spaces with exact-trace vector fields. Fancy words fer fancy generative modelin' o' functional data. 🦜

## 🦜 AI Dev Tools o' the Trade 💀

- **[higgsfield-ai/higgsfield](https://github.com/higgsfield-ai/higgsfield)** — Shiver me timbers, a fault-tolerant, highly scalable GPU orchestration framework fer trainin' models from billions to trillions o' parameters. If yer cluster be more rowboat than man-o'-war, this be the cannon ye need. 💀

- **[Claude Code v2.1.277: AGENTS.md support and egress-boundary gateway proxy](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)** — Now reads `AGENTS.md` when no `CLAUDE.md` exists (configurable under Project instructions), though not yet on Bedrock/Vertex/Foundry. Also adds `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` fer gateways whose only egress be a forward proxy, so every outbound request be routed through the gangplank. ⚓

- **[yynxxxxx/Codex-X](https://github.com/yynxxxxx/Codex-X)** — A cross-platform visual helm fer OpenAI Codex desktop/CLI: provider/API switchin', session sync, prompt injection, Skills/MCP management, an' TOML config visualization. All the knobs, none o' the CLI yak-shavin'. 🏴‍☠️

- **[CLIProxyAPI: Wrap coding agents as OpenAI/Gemini/Claude-compatible APIs](https://github.com/router-for-me/CLIProxyAPI)** — Wraps Antigravity, ChatGPT Codex, Claude Code, Grok Build, Muse Code, an' Davin as OpenAI/Gemini/Claude/Codex-compatible API services. Free Gemini, GPT, Grok, an' Claude models through standard API calls — arrr, that be a fine trick. 🦜

- **[mcpc: Universal command-line client for Model Context Protocol](https://github.com/apify/mcp-cli)** — A universal CLI client fer jabbin' any MCP server from the terminal, with multiple transports, streamin' responses, an' easy config. Handy fer testin' an' debuggin' MCP servers before they send ye to Davy Jones' locker. 💀

## Today's Synthesis

Arr, here's a mutiny worth plotin': when ye stack **[cgh](https://pypi.org/project/cgh/0.13.0/)**'s MCP surface with **[MCPShark](https://news.ycombinator.com/item?id=46220577)** and **[mcpc](https://github.com/apify/mcp-cli)**, ye get a proper debugging loop fer agent tooling. Say yer agent be fetchin' repo context through cgh's 50 MCP tools — but the answers come back wrong, or not at all. Before ye blame the model, point MCPShark at the traffic and watch the actual request/response pairs sail by. That's where ye spot the real scallywag: a truncated tool result, a malformed JSON payload, or a tool call that never left the ship. Then grab mcpc, the universal CLI client, and replay that same call directly against cgh's MCP server to isolate whether the fault be in the tool or the agent. Two tools that usually sail different routes — one fer inspection, one fer direct pokin' — with cgh as the booty they're both plunderin'. No more guessin' whether yer MCP server be lyin' to ye; now ye can catch it red-handed.
