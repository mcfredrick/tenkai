Tenkai Daily — November 15, 2026

November 15, 2026 llm open-source releases

Model Releases

  • Haru-4B 🤖 — Full-duplex speech-to-speech model for audio-to-audio conversation. Useful if you’re building real-time voice agents; less useful if your pipeline is text-first and you don’t want to babysit audio streaming.
  • Sophon-Realtime-v1 🤖 — Another full-duplex speech-to-speech model aimed at expressive voice agents and paralinguistic cues. Supports any-to-any audio/text modalities, which is handy for latency-sensitive voice UX.

Open Source Releases

  • free-claude-code 6.19.31 🛠️ — Local proxy that routes coding agents to OpenAI-compatible providers. Good if you want to swap backends without rewriting every client; check auth and provider quirks before trusting it in CI.
  • aisecuritywarden 0.7.9 🔥 — Client library for AI-agent security with scoped, revocable machine tokens, encrypted secrets, and human approval gates. Worth a look if your agents need credentials without becoming an incident report.
  • vouchwell 0.8.2 — Python SDK for tamper-evident receipts of agent actions, wire-compatible with its CLI. Useful when you need an audit trail that isn’t just “the model said it did.”
  • ai-costs 2.11.2 — Calculates AI-assisted work cost by comparing on-disk usage with API-only equivalents and vendor quotes. Nice for finance-adjacent engineering, assuming your usage tracking is accurate.
  • aisignoff 1.0.0rc4 📄 — Release candidate for declaring AI generation, human review, and AI review levels per file using REUSE-style metadata. Relevant for provenance and compliance in AI-assisted repos; still an RC, so expect rough edges.
  • tpu-inference 0.33.0.dev20261115 — Dev build for TPU inference support. The listing is thin on description, changelog, or benchmarks, so treat it as a moving target until you test it.

Today’s Synthesis

If you’re wiring coding agents into real repos, don’t just let them edit files and hope for the best. Pair aisecuritywarden with vouchwell and aisignoff to build a lightweight “agent change receipt” pipeline. Use aisecuritywarden for scoped, revocable machine credentials and human approval gates so the agent can’t grab your cloud keys or CI secrets just because a prompt asked nicely. Have vouchwell emit tamper-evident receipts for every tool call, patch, and approval event, then attach aisignoff metadata to the resulting diffs so reviewers can see what was AI-generated, what was human-reviewed, and what still needs eyes. In practice: the agent requests a change, the security layer checks permissions, the receipt records the action, and the PR carries provenance tags. That gives you an audit trail that survives postmortems, compliance reviews, and the inevitable “why did the model touch this file?” Slack thread before someone asks for a board-level answer.
