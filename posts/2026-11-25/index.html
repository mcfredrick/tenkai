Tenkai Daily — November 25, 2026

November 25, 2026 llm open-source releases

Model Releases

  • prism-ml/Ternary-Bonsai-2.5-27B-GGUF — A ternary 2-bit quantized 27B model for on-device inference with CUDA and Metal backends. It claims hybrid attention, agentic tool calling, speculative decoding, and multi-token prediction; whether that survives 2-bit quantization is the real question. 🤖
  • nari-labs/Qwen3.8-27B-NariQ-GGUF — A GGUF distribution of Qwen3.8-27B aimed at coding-agent and llama.cpp workflows. It references arXiv papers, which is either a good sign or a warning label; useful if you’re running local agentic coding inference.
  • AtomicChat/Inkling-2-Mini-Uncensored-GGUF — A GGUF build of an uncensored LoRA adaptation of Inkling-2-Mini for llama.cpp. Relevant for local image-text-to-text inference if you need modified alignment behavior and don’t mind the asterisks.
  • RadixArk/DaisyRose-27B — A Qwen3.8-27B fine-tune tagged with reinforcement learning and conversational image-text-to-text. Interesting for RL-aligned multimodal chat experiments; less interesting if you just want a vanilla text model.

Open Source Releases

  • turbo-attn 0.93.2 — A turbo-attn release with CUDA graph-enabled kernels and an attention backend for vLLM, SGLang, and friends. It builds on TurboQuant near-lossless KV cache compression, so it’s worth a look if you’re squeezing memory and throughput in LLM serving. 🛠️
  • snowllm 0.4.0.dev1 — A dev release with hand-written HIP kernels for LLM inference on AMD Ryzen AI Max / Strix Halo. Low-level kernel work for AMD hardware; useful if you’re chasing inference performance on Strix Halo, otherwise a curiosity.
  • Claude Code v2.1.332 adds MCP server skills and PreSkillShellCommand hook — Beta support for skills exposed by MCP servers, shown as server:skill in the slash menu. Adds a PreSkillShellCommand hook that can inspect or refuse inline shell commands as skills load — handy if you want a gate before your agent starts running things. 🔥
  • Goose v1.61.0 adds Gemini 4 Neon and secret MCP headers — Adds Gemini 4 Neon to the model catalog and puts the provider before the model name in the selector. Also treats all headers in mcpServers ACP configs as secret, which should reduce accidental exposure.

Today’s Synthesis

If you’re trying to make local coding agents less of a trust exercise, wire nari-labs/Qwen3.8-27B-NariQ-GGUF into a guarded agent loop instead of letting it loose in your shell. Use Claude Code v2.1.332 adds MCP server skills and PreSkillShellCommand hook to expose MCP-backed skills as server:skill, then attach a PreSkillShellCommand hook that logs or blocks obvious footguns—writes outside the repo, package installs, credential scraping, recursive deletes—before the skill runs. Keep Goose v1.61.0 adds Gemini 4 Neon and secret MCP headers in the same setup so MCP headers stay marked secret and don’t leak into chat logs. Start with read-only skills, measure how often the hook fires, then tighten rules until the agent can run tests without asking permission for every edit. The practical build is a small repo-local config: Qwen handles offline edits, Claude Code gates skill execution, Goose keeps provider headers boring, and keep the audit logs somewhere boring as well.
