Model Releases

  • OCRia-nano-1 — ONNX OCR and doc-parsing model that turns PDFs into markdown, pulls out tables and layout, and handles multilingual image-to-text. CPU-oriented, so it’s the rare document-AI component you can run without renting a GPU.
  • ERNIE-5.5-Flash-Preview — Baidu’s Apache-2.0 MoE text model with agent capabilities and FP8/8-bit deployment metadata. Open license plus real quantization paths means you can evaluate it instead of filing a sales request.
  • Ling-3.2-air — MIT-licensed multimodal MoE in Safetensors, shipping FP8 and eval-result metadata. Open-weight VLM tinkering without the license archaeology.
  • LingSante-3.1-flash — MIT hybrid text model with FP8 support, aimed at open-weight conversational deployment. Handy if you’re benchmarking quantization quality on your own prompts rather than a leaderboard’s.

Open Source Releases

  • polanon 0.4.4 — Reversible PII masking for LLM calls — Masks PII before prompts leave your network, with checksum-validated Polish identifiers (PESEL, NIP, REGON, IBAN) and stable reversible tokens. Streaming restore de-tokenizes on the response path, which is the part most masking libraries quietly skip.

Research Worth Reading

  • SkillPrivus: Uncovering Privacy-of-Use Harms in Agentic Skills 📄 — Measures privacy harm from skills that do precisely what they advertise: inferring sensitive attributes, retaining data they don’t need, disclosing to unintended recipients. A measurement framework for installable skill ecosystems, which is about to become an actual compliance question.
  • Reinforcement Learning Unlearns Corrupted SFT Reasoning — RL recovers reasoning even when the preceding SFT corpus is heavily corrupted, tested across 361 corruption configs on GSM8K varying error type, location, and trace-answer consistency. Implies outcome-based RL overwrites bad demonstrations instead of inheriting them.
  • Know Your Context Bank: Repairing Inconsistency and Measuring Generalization in Context-Aware Text-to-SQL — Enterprise text-to-SQL “context banks” accrete example queries and metric definitions that were each validated locally and never checked against each other. Proposes inconsistency detection and repair, plus a way to measure generalization beyond the bank.
  • MedicalRSI: Medical Recursive Self-Improving Agents via Clinical Model-Harness Co-Evolution — Deployed medical agents are static and repeat the same error classes patient after patient. Co-evolves model and harness from accumulated experience instead of patching weights or scaffold alone — relevant if you’re designing agent loops.
  • Search From the Start: Search-Native Pretraining for Language Models — Argues search gets bolted on during post-training while pretraining still optimizes static next-token prediction. Proposes teaching retrieval behavior from ordinary corpora during pretraining; worth your time for tool-use training curricula.
  • Weight-Space Programming Writes In-Context Learning and Matches Fine-Tuning in Language Models — One model rewrites another’s weights with no gradient descent: examples compile into a weight update that lets a weaker model do a task with an empty prompt. Six tasks, four model configs, plus analysis of what’s actually being encoded.

AI Dev Tools

  • Claude Code v2.1.331 adds Code Mode across cloud platforms 🛠️ — Code Mode now runs in terminal sessions on Bedrock, Google Cloud Agent Platform, Microsoft Foundry, and Claude Platform on AWS. Also adds oidc.groups_jsonpath for gateway group extraction (a subset of RFC 9535 JSONPath) and an API connectivity diagnostics section.
  • NousResearch/hermes-agent — Open-source agent framework built to persist and adapt across sessions, targeting coding-agent workflows across multiple LLM providers. Worth a look if your agent’s memory resets every time the container restarts.

Today’s Synthesis

Persistent agents are where privacy debt compounds: hermes-agent remembers across sessions, so every retained transcript becomes part of the blast radius. The cheap fix is to stop treating memory and skills as separate trust domains. Put polanon 0.4.4 in front of every hermes-agent prompt and response path: mask Polish identifiers and other PII before the request leaves the network, keep the reversible tokens stable, and let streaming restore de-tokenize the reply. Then borrow SkillPrivus ’s harm taxonomy as a pre-install gate for any skill the agent can load — infer sensitive attributes, retain data it doesn’t need, disclose to unintended recipients — and reject or sandbox skills that fail. Concretely: log each skill manifest, run the SkillPrivus probes in CI, and fail the build when a skill’s declared behavior crosses a retention or disclosure line. That gives you a persistent coding agent whose memory is useful without turning every restart into a new data-retention incident.
