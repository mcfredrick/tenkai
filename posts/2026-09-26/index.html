Model Releases

  • nvidia/Nemotron-3-Diarization — NVIDIA’s streaming speaker diarization system integrates Nemo, SortFormer, and GGuF quantization across recent arXiv preprints, delivering real-time speaker tagging and audio-frame classification for production audio pipelines. 🤖

Open Source Releases

  • NVIDIA Model-Optimizer: Unified SOTA Model Optimization Library — Unified open-source library implementing state-of-the-art optimization techniques including quantization, distillation, pruning, NAS, and speculative decoding, compressing models for TensorRT-LLM and TensorRT deployment. 🛠️
  • triepick 0.1.0 — Implements a trie-planned candidate scoring algorithm for user-managed vLLM deployments, optimizing token selection and batching efficiency in LLM serving systems while reducing computational overhead. 📦
  • closecode-ai 0.2.0 — Agentic terminal coding assistant framework built on LangGraph, OpenRouter, and MCP, enabling automated code generation and terminal interactions via LLM agents for programmable coding pipelines. 🛠️
  • promptdrift-ci 0.3.1 — CI-integrated framework for regression testing LLM prompts, automatically detecting prompt drift and behavioral shifts across model versions, temperature changes, or dataset modifications for stable production workflows. 🔧
  • Imbad0202/academic-research-skills - Academic research pipeline for Claude Code — Provides academic research skills for Claude Code covering the full pipeline from research → write → review → revise → finalize, automating literature reviews, peer review, and final paper generation. 📄
