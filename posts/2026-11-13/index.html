November 13, 2026 llm open-source releases

Model Releases

  • Zyphra/ZONOS3-Mini — Multilingual TTS with voice cloning, shipped in both Safetensors and GGUF. 🤖 The GGUF build is the interesting part — it means you can actually run this somewhere other than a datacenter GPU.
  • Cactus-Compute/mirage — A single VLM claiming zero-shot detection, segmentation, classification, VQA, and document QA. One checkpoint that’s merely okay at five tasks is usually worse than five small models that are good at one each, so benchmark before you refactor anything.

Open Source Releases

  • claude-code v2.1.323 — Experimental Code Mode: rather than one tool call per round trip, Claude writes JavaScript that calls its tools. Fewer model round-trips, more surface area for generated code to do something nobody asked for — hence the opt-in controls at both user and org level. Also adds engines["claude-code"] to plugin.json so plugins can declare version constraints instead of breaking mysteriously.
  • opencode v2.3.0 — Background subagents are now the default behavior: they return immediately, keep working, and report back once idle while the parent session carries on. Transcripts also got quieter, which is the sort of change you only notice by how much you stop noticing it.
  • xformers 0.0.36 — Routine bump on the composable Transformer building blocks library. 🛠️ Not thrilling, but if you’re pinned to an old version purely for the attention kernels, skim the changelog before your next dependency standoff.
  • connectpak 0.1.0 — Read-only MCP connectors for 24 SQL, NoSQL, graph, and vector engines behind one command. Read-only-by-default is the correct instinct for pointing an agent at a database. The 0.1.0 is also the correct instinct for calibrating your expectations.
  • Likely7/Veyra-NRVideo — Windows playback and capture tool with live preview for video files, images, and capture cards. It advertises “AI super resolution,” “DLSS5,” and frame generation — DLSS5 does not exist, which tells you roughly how carefully the rest of that feature list was written. 🔥 for the capture-card preview if nothing else.
  • opencode process-daemon v0.5.2 — Publishes @opencode/pty 0.5.2 at protocol 8 to npm. Pure plumbing for OpenCode’s process daemon and PTY integration; relevant only if you’re building on that layer, otherwise just a number to skip past.

Today’s Synthesis

Wire claude-code v2.1.323 ’s experimental Code Mode to opencode v2.3.0 ’s background subagents and put connectpak 0.1.0 behind the database door. The practical move is a narrow “incident triage” agent: Claude writes a small script that fans out read-only queries, opencode subagents keep running after the parent returns, and connectpak supplies the read-only MCP connectors so nobody hands an LLM a production write key. Start with one read-only replica, an allowlist of schemas, hard timeouts, and a canary query that must return known rows. Log every generated query and tool call, then diff the results against a boring SQL dashboard for a week before trusting it for real incidents. Use the plugin version constraint in claude-code to keep the harness from drifting, and keep connectpak at 0.1.0 expectations: useful plumbing, not a compliance story. If the script starts inventing joins, kill the workflow and fall back to plain old dashboards.
