Open Source Releases

  • forcefield 0.8.1 — 🛠️ A zero-dependency guardrail library for prompt-injection detection, PII redaction, content safety, rate limiting, abuse detection, tool governance, and security evals. Useful if you want LLM app safety without dragging in a huge dependency tree.
  • safetypulse 0.1.2 — Adds a Circuit Integrity Score for a cheap check that fine-tuning hasn’t quietly degraded refusal behavior. Worth a look if you keep adapting models and need a smoke test for safety regressions.
  • datris-mcp-server 1.62.0 — MCP server for data pipeline operations: ingestion, validation, transformation, analysis, and querying. It plugs into databases, vector stores, object storage, and streaming systems.
  • ai-sessions 3.22.1 — A terminal browser and cross-harness bridge for coding agents like Codex, Claude Code, OpenCode, and Grok. Handy if you’re herding multiple assistants from one interface.
  • metergraphrelay 0.8.0 — Moves LLM trace data between systems, pulling from providers and pushing into MeterGraph. Useful for observability and telemetry plumbing around LLM apps.

Research Worth Reading

  • TOUMAII: A 4.5M-Pair Tool-Calling Preference Dataset and Its Source-Agnostic Generator — 📄 A 4.5M-pair preference dataset for tool calling, built around correct API calls versus plausible wrong alternatives. Also ships a source-agnostic generator, which is the interesting part if you need tool-use training data across environments.
  • CodeReviewBench: An Automated Benchmark for Evaluating the Software Factory — An automated benchmark for AI code review quality in realistic software workflows. It fixes a common benchmark flaw by using PR-author judgments instead of third-party reviewers.
  • Don’t Discard Your Rollouts: Reusing Teacher RL Traces for Student Distillation — Looks at reusing teacher RL rollouts, including multiple completions and rewards, for student distillation instead of regenerating data from the final teacher. If you’re burning compute on PPO/GRPO-style post-training, the cost angle is the point.
  • Budget-Aware Predict-and-Verify Theorem Proving with Heterogeneous LLM Solvers — BudgetPV routes subgoals to different LLM solvers based on capability and inference cost, then uses predict-and-verify to cut wasted computation. Relevant if you’re orchestrating multiple solvers and care about cost-efficient reasoning.
  • Self-Evolving Beyond Human-Crafted Experience for EDA Scripting — ZhuLong-SE is a self-evolving agent for EDA scripting that learns from execution feedback instead of relying only on hand-crafted knowledge. It targets sparse proprietary APIs and silent failures, which are exactly the annoying parts of EDA toolchains.
  • Keep the Process, Change the Supplier: Runtime Governance for Tool-Using AI Agents — Proposes an execution boundary that mediates tool-using agent actions, separating proposals from business-controlled authorization, context disclosure, and supplier selection. The Open Process Control Plane records uncertain or external effects, which is useful if you need runtime governance instead of vibes.

  • OpenCode v2.4.0 — 🛠️ Adds a built-in desktop browser that can import profiles and extensions from common browsers. The persistent profile lets chat links open signed in and lets the agent read and drive the same pages.

Today’s Synthesis

If you’re distilling a teacher into a student, you’re not just copying capability. You’re copying its refusals, its tool-call habits, and whatever else it picked up along the way. That’s the pitch behind Don’t Discard Your Rollouts : the traces are already paid for, so mining them for near-miss cases costs you almost nothing. Pair that with safetypulse ’s Circuit Integrity Score and you’ve got a cheap gate. Run the student over a fixed prompt set before and after each distillation run, and fail the build if refusal behavior drifts more than a couple of points. Then add TOUMAII ’s plausible-wrong tool calls to the same harness. Those are exactly the inputs that slip past a student that learned API shapes from a teacher that never got corrected. Concretely: one CI job, three evals, one threshold, no new training data. The rollouts you already have are the cheapest safety regression suite you’ll ever build. The alternative is finding out in production that your 8B model now happily approves wire transfers.
