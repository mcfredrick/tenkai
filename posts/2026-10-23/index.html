Research Worth Reading

  • D-Skill: Distilling Teacher Knowledge through Agent Skills — Addresses the transfer of capabilities from frontier LLM agents to smaller models via skill distillation, bypassing traditional parameter-level knowledge distillation that requires student weight access and extensive retraining. The method extracts high-level agent skills as executable prompts or in other compact forms.

  • MoEZip: Routing-Aware KV Cache Compression for Sparse Mixture-of-Experts LLMs — Proposes MoEZip, a routing-aware KV cache compression method tailored for sparse Mixture-of-Experts language models, addressing the linear KV cache growth issue in long-context inference. It leverages expert routing patterns to selectively prune and cache attention states, reducing memory footprint.

  • A Small Model Asks Better: Fine-Tuning Query Clarification for Retrieval-Augmented Generation — Introduces a fine-tuning framework for query clarification in RAG systems, addressing ambiguous or ill-formed user queries in multi-turn conversational settings. The work proposes targeted clarification mechanisms grounded in prior dialog context and retrieved document relevance, improving passage retrieval.

  • SpecEvo: Speculative Evolution with Large Language Models for Cost-Efficient Scientific Discovery — Presents SpecEvo, a multi-LLM framework that coordinates lightweight and frontier models to perform evolutionary search for scientific discovery, avoiding uniform expensive reasoning. It selectively applies costly computation to promising trials and prunes redundant/saturated ones, reducing overall compute.

  • Back Up Before You Regret: Measuring Backup Awareness and Automating Backup in Coding Agents — Introduces RegretBench, a benchmark evaluating coding agents’ backup awareness—the recognition that actions may modify state needed later, and the ability to preserve it proactively. The work automates backup mechanisms by tracking state dependencies and snapshotting critical artifacts before high-risk operations.

  • DiffResearch: Accelerating Deep Research with Diffusion Language Models — Presents DiffResearch, an open multi-agent deep research system that replaces autoregressive planning and writing with diffusion-based language models to reduce end-to-end latency. The framework iteratively plans, gathers evidence, synthesizes and revises using continuous-state diffusion trajectories.

Today’s Synthesis

Running sparse Mixture-of-Experts LLMs in production? MoEZip addresses the KV cache bottleneck by routing-aware pruning of attention states, reducing memory overhead without retraining. Pair that with SpecEvo , a multi-LLM framework that selectively applies costly frontier-model reasoning only to promising evolutionary trials, slashing compute waste in automated discovery pipelines. Complement both with A Small Model Asks Better , which fine-tunes models to proactively clarify ambiguous user queries using dialog context, improving RAG retrieval from the first turn. For engineers, the actionable playbook is straightforward: integrate MoEZip into your MoE inference backend, hook SpecEvo’s selective computation into your agent loops, and add query clarification as a pre-retrieval step. The payoff: significantly lower GPU hours, faster end-to-end latency, and more relevant answers even when users fire vague or multi-turn prompts. It’s a three-part lever for cost-efficient, high-throughput LLM deployment. If you’re maintaining a codebase with frequent agent interactions, wrap your retrieval pipeline with the query clarifier, instrument MoEZip’s routing logs to monitor cache savings, and let SpecEvo’s trial pruning decide which sub-problems get frontier-model time. This triad turns theoretical efficiency gains into measurable production wins.
