Research Worth Reading

  • FARO: Function‑Space Adaptive Return‑to‑Risk Optimization via Cross‑Block Equal‑Risk‑Contribution Budget Allocation — An adaptive optimizer that splits updates across attention and MLP blocks using equal‑risk‑contribution, swapping hand‑crafted schedules for a data‑driven scheme. Could simplify LLM training, but you’ll still need to verify stability 🤖.
  • Kernel‑based Interpolatory Methods for Context Compression of Attention Mechanisms — Uses kernel interpolation to shrink KV‑cache size, turning quadratic attention cost into linear or near‑linear while keeping retrieval quality. Straight‑up win for inference scaling 🔥.
  • HyperRepair: Recovering Forgotten General Capabilities of Fine‑Tuned Language Models — A framework that balances specialization and retention after domain‑specific fine‑tuning, avoiding full re‑training. Saves cycles when you need to keep the model from losing its “general” tricks 🛠️.
  • Don’t Just Impute, Detect: Task‑Aware Diffusion Pipelines for Edge Anomaly Detection — Jointly imputes missing multi‑sensor blocks and detects anomalies, training imputers for detection rather than just MSE. Moves beyond the classic impute‑then‑detect shuffle, which is a relief for edge pipelines 📄.
  • Unsupervised Feature Selection Using Local Intrinsic Dimensionality — Extended Version — LIDFS leverages local intrinsic dimensionality to prune features without labels, delivering better efficiency when you lack ground‑truth. Handy for raw sensor streams or log data 🔥.
  • Certified Behavioral Retention for Continual Adaptation with Held‑Out Anchors — CABA introduces a candidate‑agnostic post‑update gate that checks model changes against a budget for protected behavior using historic anchors. Safer continual learning, but adds a verification overhead 🛠️.
