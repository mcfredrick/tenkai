Today’s Synthesis

Two things that should never be combined: LLM agents and undeclared tool calls. The closed-world resolution paper identifies a failure mode where agents call tools that don’t exist and pass arguments nobody declared — and tool selection and gating miss it entirely. The fix is mechanical: enforce declared schemas at the boundary. If you’re building with Mcp-Agent , that means a validation middleware that checks every tool call against its declared schema before dispatch — not a prompt instruction, an actual hard check. This matters double when the tool is something like pg-mcp , where a hallucinated argument isn’t a fun bug, it’s a malformed query against your production database. The paper’s point is that this class of error survives selection and gating, so the schema contract has to be enforced in the harness, not the model. Treat MCP’s declared schemas as an API contract, validate every call, and let the agent fail loudly on a 400 instead of silently doing the wrong thing.
