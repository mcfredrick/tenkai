📄 Research Worth Reading

  • ContextLure: Exploiting Benign Conversation History for Indirect Prompt Injection — Shows how benign conversation history can be seasoned into an indirect prompt injection against tool-using agents. If you’re building long-horizon agents, this is the security warning label on the cranberry can. 🦃

  • Taxi: Analyzing Agents at (Real) Scale — A system for debugging, clustering, and monitoring agents at millions of steps, with a taxonomy over agent traces. It’s the big serving tray for large-scale agent trace analysis. 🍂

  • One Step, Four Clocks: How GUI Agents Fall Out of Step — Models GUI-agent failures through four timing events, showing latency alone doesn’t explain actions going stale mid-deliberation. Introduces ChronotopeGym for studying desynchronization failures, like a clock that missed dinner. 🥧

  • Neighbor Crowding Predicts Feature Stability in Sparse Autoencoders — Finds that crowding in SAE feature space predicts stable features versus initialization artifacts. Useful for mechanistic interpretability when you don’t want to train a pile of SAE seeds just to compare notes. 🌽

  • KiRA: Kronecker Input-Gated Rank Adaptation for Parameter-Efficient Fine-Tuning — A PEFT method using Kronecker-factored, input-gated rank adaptation to get past the fixed low-rank adapter bottleneck while staying parameter-efficient. For engineers who want more capacity without a full model roast. 🍂

  • One Token, Many Lessons: Sliding-Window Attention within Gated Delta Networks — Reads linear attention as test-time regression, where the recurrent state is an online-learned model, then adds sliding-window attention to gated delta networks. Relevant for long-sequence, memory-efficient architecture work. 🦃

Today’s Synthesis

For the holiday table, build a local agent-testing buffet: use agent-strace 0.125.0 to capture tool calls, LLM requests, and decision points while your agent tries to book a dinner reservation or merge a pull request. Then replay a benign-looking conversation history using the attack pattern from ContextLure , because innocent context can still season a prompt-injection path if your tool loop trusts too much. Finally, dump the resulting traces into Taxi and cluster failures by its taxonomy, so you can separate “model misunderstood the task” from “tool call raced the user’s intent” or “retrieved context went stale.” The engineer move is to turn this into a pre-release check: record a trace set, reheat it with adversarial-but-polite history, then gate deploys on new failure clusters. Keep the harness local, version the traces, and rerun it whenever prompts, tools, or model routing change. That gives you a repeatable way to inspect agent behavior before users find the burnt bits. If you already have CI, run it on every prompt change and attach the failing trace to the ticket. 🦃
